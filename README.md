# Mountain100

日本百名山管理用 iOS アプリ

深田久弥『日本百名山』（1964年）に選定された100山の一覧を表示し、登頂した山をチェックボックスで記録できます。

## 機能

- **百名山一覧** — 書籍掲載順（概ね北から南）に100座を表示。山名・読み・都道府県・標高を一覧で確認できます
- **登頂チェック** — 各行のチェックボックスをタップして登頂記録を保存（`UserDefaults` に永続化され、アプリを閉じても保持されます）
- **進捗表示** — 登頂数（○/100座）とプログレスバーをヘッダーに表示
- **絞り込み** — 「すべて / 登頂済み / 未登頂」のセグメントで切り替え
- **検索** — 山名・読み・都道府県で検索
- **詳細画面** — 最高峰・標高・山域などの基本情報と登頂トグル

## 動作環境

- Xcode 16 以上
- iOS 17.0 以上

## ビルド方法

1. `Mountain100.xcodeproj` を Xcode で開く
2. シミュレータまたは実機を選択して Run（⌘R）

## プロジェクト構成

```
Mountain100/
├── Mountain100App.swift        # アプリのエントリポイント
├── Models/
│   ├── Mountain.swift          # 山のデータモデル
│   └── MountainStore.swift     # データ読み込み・登頂記録の永続化
├── Views/
│   ├── MountainListView.swift  # 一覧画面（検索・絞り込み・進捗）
│   └── MountainDetailView.swift # 詳細画面
├── Resources/
│   └── mountain100.json        # 百名山マスタデータ（100座）
└── Assets.xcassets
```

## データ

`Mountain100/Resources/mountain100.json` に、各山の以下の情報を収録しています。

| フィールド | 内容 |
|---|---|
| `id` | 掲載順の通し番号（1–100） |
| `name` | 山名（書籍表記） |
| `kana` | 読み |
| `highest_peak` | 最高地点の峰名（山名と異なる場合のみ） |
| `elevation_m` | 標高（m、最高地点） |
| `prefectures` | 所在都道府県 |
| `range` | 山域 |
